# Dork Searcher 2.0

Scope-aware search, Wayback, Certificate Transparency, DNS, and bounded HTTP
reconnaissance for authorized bug bounty and security research.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python -m src.cli
```

See [the complete documentation](docs/README.md) for the evidence model, command
reference, scope controls, installation, and operational-safety guidance.

Use only on systems you own or have explicit permission to assess.
